# AI 安全测试平台 — 界面设计文档

> 基于 5 维度（布局 / 色彩 / 字体 / 组件 / 交互）的结构化界面设计描述。
> 技术栈：Next.js (App Router) + Tailwind CSS + shadcn/ui。

---

## 1. 布局（Layout）

### 1.1 整体结构

采用 **「顶部导航 + 侧边栏 + 内容区」** 三段式管理后台布局：

```
┌────────────────────────────────────────────────────┐
│  顶部导航栏 (Header, 固定, h-14)                     │
│  Logo + 平台名        搜索框        通知 / 用户头像    │
├──────────┬─────────────────────────────────────────┤
│          │                                         │
│  侧边栏   │            内容区 (Main)                 │
│  (w-60,  │   面包屑 + 页面标题 + 操作按钮              │
│  可折叠)  │   ─────────────────────────             │
│          │   页面主体内容（卡片 / 表格 / 表单）         │
│  · 仪表盘  │                                         │
│  · 任务列表│                                         │
│  · 攻击模式│                                         │
│  · 测试报告│                                         │
│  · 设置   │                                         │
│          │                                         │
└──────────┴─────────────────────────────────────────┘
```

### 1.2 各区域说明

| 区域 | 内容 | 行为 |
|------|------|------|
| 顶部导航栏 | 平台 Logo 与名称「AI 安全测试平台」、全局搜索框、通知铃铛、用户头像下拉菜单 | 固定在顶部（`sticky top-0`），滚动时不消失 |
| 侧边栏 | 主导航菜单：仪表盘、任务列表、攻击模式库、测试报告、设置；底部为折叠按钮 | 桌面端常显，可折叠为仅图标（w-16）；移动端隐藏，通过汉堡菜单以抽屉形式展开 |
| 内容区 | 面包屑导航、页面标题 + 主操作按钮（如「新建任务」）、页面主体 | 最大宽度容器居中，内边距 `p-6`，内容随路由切换 |

### 1.3 页面级布局

- **任务列表页**：标题行（标题 + 新建任务按钮）→ 筛选工具栏（状态筛选、搜索）→ 任务表格卡片
- **任务详情页**：返回链接 → 标题行（目标名 + 状态徽章）→ 上下两栏卡片（基本信息 / 测试结果）→ 证据与日志区
- **新建任务页**：居中单列表单卡片（`max-w-2xl`），底部为「取消 / 提交」按钮组

## 2. 色彩（Color）

### 2.1 主色调

沿用 shadcn/ui 的语义化令牌（支持亮/暗双主题）：

| 用途 | 令牌 | 说明 |
|------|------|------|
| 主色 | `primary` | 品牌主色，用于主按钮、链接、激活态导航 |
| 背景 | `background` / `card` | 页面背景 / 卡片背景 |
| 文字 | `foreground` / `muted-foreground` | 主文字 / 次要文字 |
| 边框 | `border` / `ring` | 分割线、卡片描边 |

### 2.2 状态色

| 状态 | 颜色 | 用法 | 对应 Tailwind |
|------|------|------|---------------|
| 成功 / 完成 | 绿色 | 任务完成、测试通过、is_success=是 | `bg-green-500/15 text-green-600` |
| 失败 / 错误 | 红色 | 任务失败、表单校验错误、destructive 操作 | `bg-red-500/15 text-red-600` / `destructive` |
| 警告 | 黄色 | 高危漏洞提醒、待确认操作 | `bg-yellow-500/15 text-yellow-600` |
| 执行中 / 信息 | 蓝色 | 执行中的任务、提示信息 | `bg-blue-500/15 text-blue-600` |
| 待执行 / 中性 | 灰色 | 未开始的任务、禁用态 | `bg-gray-500/15 text-gray-600` |

### 2.3 严重等级色（业务专属）

| 等级 | 颜色 |
|------|------|
| 严重 (Critical) | 深红 `text-red-700` |
| 高危 (High) | 红色/橙色 `text-red-500` |
| 中危 (Medium) | 黄色 `text-yellow-600` |
| 低危 (Low) | 蓝色 `text-blue-500` |
| 信息 (Info) | 灰色 `text-gray-500` |

原则：所有状态色用「浅色底 + 深色文字」的徽章样式，不用大面积实心色块，保证可读性与暗色模式兼容。

## 3. 字体（Typography）

| 层级 | 规格 | 用途 |
|------|------|------|
| 页面标题 (H1) | `text-2xl font-bold` | 页面主标题，如「AI 安全测试平台」 |
| 卡片标题 (H2) | `text-base font-medium` | Card 标题、区块标题 |
| 正文 | `text-sm`（14px） | 表格内容、描述文字、表单标签 |
| 辅助文字 | `text-sm text-muted-foreground` | 次要说明、空状态提示、时间戳 |
| 徽章/标签 | `text-xs font-medium` | Badge 状态标签 |
| 等宽字体 | `font-mono` | URL、Payload、日志、证据代码片段 |

风格：现代无衬线（系统字体栈 / Geist），数字与代码用等宽字体保证对齐；行高宽松（`leading-6`），中文阅读舒适。

## 5. 交互（Interaction）

### 5.1 核心用户流程

**浏览任务（已实现）**
1. 进入任务列表页 → 显示「加载中...」→ 渲染任务表格
2. 加载失败时显示错误信息；无数据时显示空状态「暂无任务」

**创建任务**
1. 点击右上角「新建任务」→ 进入新建任务页（或弹出 Dialog）
2. 填写表单：目标名称、目标 URL、选择攻击模式（下拉）、Payload（可选）
3. 客户端校验：必填项为空时字段下方显示红色错误提示，提交按钮禁用
4. 提交后按钮进入 loading 态 → 成功：Toast 提示「任务创建成功」并跳回列表页，新任务置顶显示；失败：Toast 提示错误原因

**查看详情**
1. 点击表格某一行（或行尾「查看」按钮）→ 跳转 `/tasks/[id]` 详情页
2. 详情页用 Tabs 切换：基本信息（目标、状态、严重等级、时间）/ 测试结果（实际行为、预期行为、是否成功）/ 执行日志（等宽字体滚动区）
3. 状态为「执行中」的任务：页面轮询刷新（如每 5 秒），进度条实时更新

**任务操作**
1. 表格行尾 DropdownMenu：查看详情 / 重新执行 / 删除
2. 「删除」弹出 Dialog 二次确认（destructive 红色按钮）→ 确认后 Toast 反馈并刷新列表

### 5.2 通用交互规范

| 场景 | 反馈 |
|------|------|
| 加载中 | 页面级显示「加载中...」，表格用 Skeleton 骨架屏，按钮用 spinner + 禁用 |
| 操作成功 | 绿色 Toast，自动消失（3s） |
| 操作失败 | 红色 Toast 或表单内联错误，需用户知晓原因 |
| 危险操作 | 必须二次确认（Dialog），按钮用 destructive 样式 |
| 空状态 | 居中插画/图标 + 说明文字 + 引导按钮（如「创建第一个任务」） |
| 悬停 | 表格行 `hover:bg-muted/50`，可点击元素鼠标变手型 |
| 键盘可达 | 所有交互元素支持 Tab 聚焦，focus 显示 ring 高亮（shadcn 默认） |
